All five documents describe the current model, `abc-credit-lgbm-2026-11-19`: cost ratio 6, cut-off 0.143,
eight questions, stated income neither asked nor used. They were regenerated on 19 November 2026.
The tutorial does not describe the evaluator view; the step-by-step guide and the report do.

The model selector (new model by default, 13 November model for comparison) was added afterwards. The report, the
slides, the step-by-step guide and the project `README.md` describe it and count 18 tests. The tutorial and the
delivery guide were not rebuilt for it: they do not mention the selector, and where they say 15 tests there are now 18.
